# 登录成功（含登录后行为）

2026-10-12：按用户要求增加 Dashboard 派生漏斗条件 `login_verified`，不新增产品采集事件，不替换原 `login_succeeded`（主动登录）。

计数证据：原始事件带非空 user_id，且事件为主动登录成功、筹码峰展示/下钻、策略开启/停止、手动交易提交/成功/失败或限价单创建。共同白名单保存于 frontend/src/analytics/loginEvidence.json，JSON、SQLite、Hologres 使用相同集合。

按统一用户身份去重，并保留漏斗日期、来源、窗口与顺序条件。不能仅因匿名事件之后被映射到账号，就将匿名事件认作当时已登录。Token浏览、榜单点击、登录按钮点击等不在白名单。

这是已登录状态的行为证据，不证明本次发生新的登录或注册。派生登录状态与其来源行为可以在同一时间成立，因此“登录成功（含登录后行为）→有效分析”允许同一条筹码事件满足两步；原主动登录步骤仍保留原顺序条件。

新条件仅用于分析，不写入原始事件时间线或行为路径。北极星事件口径不变。原“登录成功”和“已登录访问”选项保留；后者包括任意带用户ID的事件，范围更宽。

验证：前端157测试、后端56测试、前端构建通过；新增用例验证匿名排除、非白名单浏览排除、下钻无需主动登录事件、同时间状态/分析、用户去重及Hologres查询身份约束。
