# 行为路径、交易监控与网站审核实施设计

日期：2026-10-11；范围为当前 LogEarn 数据分析后台，远程数据库只读，不修改产品交易和埋点代码。

## 行为路径

- 按真实会话展示实际操作顺序，不预设漏斗。提供含今日1/3/7天、首次会话行为或指定行为起点、3/5/7步、来源和已有受众筛选。
- 优先用户+session_id，候选显式会话取得完整已观测上下文，避免只取30分钟前文而把跨窗长会话当新会话。无session_id者单列30分钟推断，不混入显式会话。
- 连续同类行为折叠，保留重复访问，节点按步骤分层避免循环。保留页面/登录/钱包/Token/分析/策略/交易/邀请等已知业务事件，心跳不入图。
- 卡片：会话数、去重用户、路径种类、平均展示步数。Top路径桑基图只显示明确标注的前12种路径及覆盖占比；完整常见路径表搜索/分页，起点和节点/连线可下钻。
- 终点区分观测结束、仍在观察、窗口截止、后续折叠，不把观测停止当流失或退出。名单人数按用户去重，图形流量按会话；下钻展示同快照时间线并明确两种单位。

## 线上监控：交易成功率

- 以客户端手动交易提交事件组成批次，按用户+attempt_id精确关联终态；交易ID只在确定无冲突的别名链中补充关联，不按钱包地址或时间猜关联。
- 产品源码确认：手动交易终态status=4上报成功，3/6/7上报失败，策略自动交易不进入此埋点。
- 多钱包提交是一个批次、可能有多个订单；图表、分母和下钻分清单位。核心指标为已关联订单终态成功率（成功 / 成功+失败），不把缺失结果当失败；展示提交批次、成功/失败订单、待确认批次、混合结果、关联覆盖与数据质量。
- 同订单冲突结果或跨提交别名冲突隔离；缺关联ID、未匹配本批次终态独立下钻。已知钱包数但结果不齐为待确认；未提供钱包数不声称全部钱包成功。
- 含今日1/7/14/30天，按提交日归组；结果观察至快照事件截止，允许结果晚于提交统计期。链/来源筛选针对提交批次，未知链单列。
- 展示日趋势、按链对比、失败原因和逐批次/逐订单明细，支持时间线。交易记录表不提供统一失败全集和attempt关联，因此不拼成成功率或USD金额。

## 网站审核与修复

- 检查真实数据页能力声明、导航、统计期、日期截止、空态/错误/重试、请求竞态、图表销毁、下钻权限、表格单位、窄屏和键盘操作。
- 新页面维持按钮手动刷新；未应用筛选不被提交，同口径刷新失败保留旧结果。不能提供的模块明确标识待接入，避免显示演示零值。
- 修复审核发现的缺陷，补有意义的边界测试；通过真实API对账和登录后浏览器验收交付。保持现有用户分群和推荐功能。

## 审核发现与修复记录

| 问题 | 修复 |
| --- | --- |
| 路径默认14天超过上限 | 改为1/3/7天，默认7天且含今日；旧保存周期无效时回退 |
| 长会话只取30分钟前文，重复起点误排除 | 加载候选真实会话全部已观测上下文，指定起点从期内首次匹配行为开始 |
| 路径起点包含未提供或虚拟事件 | 只提供已观测的业务行为，排除每日访问等合成行为 |
| 交易提交与多钱包订单单位混淆 | 终态成功率、关联率、待确认、混合和钱包数未知分开；批次继续下钻订单 |
| 异常关联/重复终态可能被计为成功 | 明确ID关联、同订单去重、矛盾与别名冲突隔离 |
| 旧成功页展示未经确认USD/自动交易口径 | 远程页仅展示手动交易埋点，范围与未知覆盖明确说明 |
| 新页切换或多用户详情迟到响应 | 页面销毁增加请求代数，详情每次使用独立容器，防止旧响应覆盖当前用户 |
| 导航展开状态与可用能力不一致 | 监控菜单点击/键盘展开，选择后收起；渠道标注待接入，父菜单高亮同步 |
| 提示/页脚仍按旧用户单位，时间线使用内部名称 | 页面专属口径及单位，时间线中文事件标签，实际链名称保留原始ID |

范围仍为分析后台。未部署到生产，未修改交易产品源码或远程数据。
