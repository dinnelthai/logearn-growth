# 核心用户路径与跨天回访工作流

2026-10-24，本地实现。

## 入口与使用

1. 首页或北极星详情 → 周核心分析用户卡片 → 点击核心、持续、进入、跌出或2—3天用户人数。
2. 名单底部选择行为路径、漏斗或留存。服务端物化全部匹配名单（包括所有分页，搜索条件生效），绑定周核心指标的7个完整UTC+7自然日与快照。
3. 路径默认展示多条实际会话路径。选择具体关键行为后，可切换向前看或向后看。
4. 向前看：每个会话在统计期内首次该行为，截取它之前最近3/5/7步（含该行为）；不包含窗口之前的行为；未发生该行为的会话不计入分母。中止动作不适用。筹码查看起点包含下钻。
5. 向后看：保持原有会话语义，中止动作可选任意已支持行为。
6. 路径下方“跨天回访行为”独立计算全窗口业务行为：使用天数、至少2天使用/有效分析、首次跨天回访间隔中位数、首次与下一次使用日的首个行为。人数可下钻并继续其他模块。

## 口径和边界

- 跨天面板不随会话起点、中止或步数改变。只受人群、来源、时间窗口、快照影响；与会话图人数可能不同。
- 业务行为包括登录、页面访问等已支持路径事件；使用天数不等于有效分析天数。没有扩大周核心指标定义。
- 首次指窗口内首次观测，下一次使用日可不连续；UTC+7跨午夜可以少于24小时。回访间隔为每位跨天用户第一对使用日首事件间隔，再取中位数。
- 每位回访用户只贡献一对首行为，显示最多8组；不代表完整跨天任务链。所有天数分布和回访人数保留完整名单。
- 同周按4天筛选再观察跨天属于描述，不能证明任何路径导致习惯。验证预测性需固定首次行为窗口并观察后续成熟周；因果验证仍需实验或独立证据。本次未添加因果结论或自动触达。
- 沿用原有查询、事件数量、worker和结果体积预算，跨天使用已加载的路径业务事件，不新增远程查询。
