# 转化损失拆解与埋点验收

日期：2026-10-19，Asia/Bangkok。继续增强当前工作区的增长诊断。入口为「总览 → 增长诊断 → 转化损失 / 埋点验收」，原变化和数据可信度视图也提供入口。

## 转化损失

新增 `POST /api/metrics/conversion-loss`，复用认证、owner作业、快照、人群与下钻。支持最长31天的所选统计期；上期取紧邻本期、相同时长的窗口。

每个周期分别计算：

1. 已观测页面访问用户。
2. 访问后有明确已登录证据的用户。页面本身带账号可以同时证明访问及登录；其他登录事件必须晚于页面访问，不用后来合并出的账号身份反推之前已登录。
3. 登录证据之后明确观测到筹码查看/下钻的用户。不同事件同毫秒时不猜测先后，分析需严格晚于登录证据。
4. 不满足上述顺序证据、但确实有筹码查看/下钻的用户。仍完整计入北极星，不当作无效使用。

每期保持「北极星人数 = 顺序链路内分析人数 + 顺序证据外分析人数」。链路允许同一用户跨访问，不宣称同一会话或24小时漏斗。

两期的访问和登录分母均有效时，对访问人数、登录证据覆盖、登录后分析覆盖的6种替换顺序取平均，计算数学贡献；加上顺序证据外人数变化后与北极星变化精确对账。贡献是人当量，显示小数，不冒充实际用户名单或因果归因。分母不足时保留人数及未知比例，禁用因素拆解。

上期分析、本期未观测分析的用户互斥分组：

- 本期请求成功，但没有筹码查看/下钻事件。
- 最近分析请求的明确失败、取消、空结果、观察中、未知或冲突。
- 无上述分析请求线索时，最近登录尝试的明确失败、取消、观察中、未知或冲突。
- 再按Token浏览、登录证据、页面访问或未观测页面访问分类。

请求线索包括本期发起或本期出现终态的尝试，按同一用户、同一尝试ID关联；状态仅采用本期期末之前的证据，未来终态不反写历史。多次尝试优先核对本期明确成功，其余取最近发起的相关尝试。这些是排查证据，不是已确认流失原因；没有请求事件不能证明未发起。

所有用户指标有准确名单。上期名单新增 `list_periods` 元数据，用户详情和人群继续分析都继承上期本身的窗口，不悄悄切到本期。

查询只加载页面、登录、Token、筹码以及分析/登录尝试事件，保留必要相关历史用于跨期终态、冲突和重试核对；不加载卡片曝光、页面加载、停留检查点等无关载荷。保留150000事件/48MB预算，超预算报错，不截断后继续算比例。

## 埋点验收

新增 `POST /api/metrics/tracking-audit`。按全平台到达记录或精确event_id核验，不继承来源或用户人群；API拒绝过滤人群，避免把原始接入质量与已归一化用户池混用。

### 到达记录对账

总览按服务端 `server_ts` 的所选到达窗口统计，与客户端业务发生时间的北极星不是同一分母：

`到达记录 = 首次纳入的代表事件 + 同ID其他到达 + 未纳入记录`

同ID其他到达包括原始代表记录在更早窗口的重试，也可能存在字段冲突，不能当作新增行为。未纳入按现有规则展开：无有效事件ID/时间、去重代表记录缺身份、代表记录或唯一身份关联命中脏账号、匿名身份关联历史脏账号，以及其他排除。

另列窗口内重复ID、缺事件ID、无效客户端时间、缺身份、当前原始账号脏标记。诊断标记可能重叠，不能相加；窗口内重复数也不等于全历史去重后的其他到达数。多次读取对账不一致时明确要求新快照重查。

### event_id样本核验

- 支持粘贴每行ID、事件对象、事件数组或逐行JSON，最多100个ID、输入256KB；不接收完整HAR。
- 浏览器和服务端都按白名单清洗，只保留event_id、event_name、client_ts与安全诊断字段。账号、匿名身份、请求头、Token、签名和其他未知属性不转发、不进入验收输出。
- 在快照截止前的全历史精确查ID，不限上方到达窗口；快照后到达的事件需用最新快照重查。
- 分别展示未找到、白名单字段或身份指纹冲突、已到达但未纳入事实层、契约问题、浏览器样本不一致、读取冲突、已知诊断契约未见问题，以及没有新诊断契约的历史事件。
- 验证当前分析请求、登录尝试及页面加载6类事件的必需字段、类型、结果枚举、耗时、明确失败/取消原因。页面加载允许ready/presented分别保留。身份指纹只用于内部冲突核验，不返回客户端。
- 「纳入」只表示进入统一事件事实层，不保证计入某个具体业务指标；业务事件名称、窗口、人群和关联条件仍需符合该指标口径。

浏览器发出、HTTP响应和业务成功都是人工提供的证据，分别标记。仅查到数据库记录、仅HTTP200或仅勾选声明都不会变成端到端通过。只有提供事件名/时间等实际样本、字段一致、已知契约未见问题，且人工确认浏览器发出及采集业务成功，才显示「样本证据一致（含人工声明）」。它仍不证明独立核实了浏览器请求，也不证明连续完整采集。

可导出本次安全验收JSON。输入或声明发生变化时，旧结论立即失去可导出状态，在途旧响应不能覆盖新草稿；可显式强制获取新快照重查。导出日期按UTC+7命名。

原始重复记录最多1000条/2MB，超预算失败；事实层查找及作业资源预算沿用原机制。没有重放事件、构造线上采集、修改原始事实或放宽身份过滤。
