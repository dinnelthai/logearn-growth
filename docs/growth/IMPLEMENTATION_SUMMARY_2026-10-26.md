**文件：** `backend/src/analytics/xAcquisition.js`

#### 评分算法优化
**新增维度：**
- `teaching` 教学内容（+25 分）
- `review` 工具评测（+20 分）
- `usage` 使用证据（+15 分）
- `kol` 内容创作者类别

**优化逻辑：**
- 区分硬噪音（垃圾广告）和软噪音（有价值推广）
- 教学/评测内容推广仅轻度扣分（-10）
- 转推教学内容保留价值（-15 vs -50）

**测试结果：**
```javascript
// 教学内容
scorePost({text: '链上工具教程：如何用筹码分析工具找聪明钱'})
// → score: 60, category: 'kol'

// 垃圾广告
scorePost({text: '空投！！！加入电报群立即领取100x币！！！'})
// → score: 0, category: 'noise'

// 用户问题
scorePost({text: '求推荐：有没有好用的关联钱包工具？'})
// → score: 100, category: 'need'
```

#### 回复草稿优化
新增 KOL 识别逻辑：
```javascript
if(category==='kol'){
  return '感谢分享链上分析内容！如果您对筹码分布、关联钱包或聪明钱追踪有深入研究，欢迎试用我们的分析工具，期待您的反馈。'
}
```

保留原有用户问题回复逻辑。

#### 快速启动脚本
**文件：** `backend/scripts/kolExpansionQuickStart.sh`

**功能：**
- **步骤 1:** 从现有线索提取 Top 20 KOL 候选
- **步骤 2:** 检查当前关键词和采集状态
- **步骤 3:** 交互式修改采集预算

**用法：**
```bash
cd backend
./scripts/kolExpansionQuickStart.sh 1  # 查看高质量线索
./scripts/kolExpansionQuickStart.sh 2  # 检查当前配置
./scripts/kolExpansionQuickStart.sh 3  # 修改预算
./scripts/kolExpansionQuickStart.sh all  # 依次执行所有步骤
```

## ⚠️ 风险与应对

### 风险 1：关键词扩展导致噪音增加
**监控：** 每日检查 `category='noise'` 占比
**阈值：** > 60% 触发优化
**应对：**
- 暂停效果最差的 2 组关键词
- 增加排除词
- 调整评分权重

### 风险 2：预算增加但转化率不提升
**监控：** 7 天内未新增 ≥ 10 个合格候选
**应对：**
- 回调预算到 $3/天
- 优化现有候选合作转化
- 人工补充种子 KOL

### 风险 3：KOL 内容与产品适配度低
**监控：** 前 3 个合作 KOL 带来用户 < 5 个
**应对：**
- 增加"产品适配度"审阅维度
- 优先筛选实际使用分析工具的 KOL
- 提供更长试用期验证真实场景
