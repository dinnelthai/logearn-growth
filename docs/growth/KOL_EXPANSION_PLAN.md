# 中文 KOL 获客扩展方案 | 2026-10-26

## 一、现状分析

当前系统通过 X 关键词自动采集，但只有 **8 个中文 KOL 候选**，规模严重不足。

核心问题：
1. 关键词覆盖面窄（仅 2 组中文关键词）
2. 评分规则过严（推广内容直接低分）
3. 日预算过低（$1/天，约 3-4 次搜索）
4. 人工筛选瓶颈（候选→合作转化率低）

---

### 2. 优化评分规则

**当前问题：推广内容一刀切扣分**

建议调整 `scorePost` 函数：
- 区分"垃圾广告"和"工具推广/教学"
- 允许有推广链接但同时有实质内容的帖子
- 增加"教学"维度：教程、案例、操作步骤

**新增评分维度：**
```javascript
// 教学特征（+25分）
const teaching = /(教程|案例|步骤|演示|实操|手把手|详解|深度解析|完整流程)/i.exec(text)

// 工具评测（+20分）
const review = /(实测|对比|优缺点|适合|推荐理由|使用体验|评测)/i.exec(text)

// 降低推广惩罚：如果是工具类内容，推广不扣分
if (noise && (tool || teaching || review)) {
  score -= 20  // 改为轻度扣分
} else if (noise) {
  score -= 65  // 保持原逻辑
}
```

### 3. 增加采集预算

**当前：$1/天 ≈ 3-4 次搜索**

建议调整：
- 短期（7天）：$5/天 = 约 16 组关键词/天
- 中期（30天）：$3/天 = 约 10 组关键词/天

**预算分配：**
- 周一/周五：$5（高频更新日）
- 周二至周四：$3
- 周末：$2

## 三、方案 B：半自动 KOL 发现（7-14 天实施）

### 1. 从现有数据源扩展

**A. 从 X 获客线索中提取 KOL**
```sql
-- 从已有的 x_acq_leads 中筛选高质量账号
SELECT 
  author_id, username, name, followers, bio
FROM x_acq_leads
WHERE followers > 1000
  AND score >= 50
  AND category IN ('need', 'research')
  AND stage NOT IN ('dismissed', 'closed')
ORDER BY followers DESC
LIMIT 50
```

**B. 扩展采集：关注者网络**
- 找到已验证的优质 KOL（如 CryptoCharming）
- 采集其"关注列表"和"互动频繁的账号"
- 优先筛选：中文内容 + 链上分析标签

**C. Twitter List 导入**
- 手动维护 1-2 个"中文 Web3 工具 KOL"列表
- 一键导入列表成员到候选池
- 自动采集最近 20 条推文

### 2. 候选池管理优化

**当前上限：500 个账号**

建议分层管理：
- S 级（Top 20）：重点合作，每周人工审阅
- A 级（50个）：优质候选，每月刷新画像
- B 级（100个）：观察池，季度评估
- C 级（330个）：冷备份，不占用采集预算

### 3. 自动化画像更新

**当前：需人工触发 `/kol/accounts/:id/refresh`**

建议：
- 为 S/A 级 KOL 设置自动刷新（每周一次）
- 当检测到"粉丝增长 >20%"或"近期爆款帖子"时触发刷新
- 预算允许时，批量刷新 B 级账号

## 七、成功指标

### 北极星指标
- **候选池规模**：30 天内从 8 个增长到 80-100 个
- **合格率**：至少 30% 的候选通过人工审阅（24-30 个）
- **合作转化率**：10-15% 的合格候选达成合作（3-5 个/月）

### 质量指标
- 平均粉丝数 > 5,000
- 中文内容占比 > 80%
- 链上分析/工具教学内容占比 > 50%
- 近 30 天活跃度 > 10 条原创推文

### 成本指标
- 单个合格候选采集成本 < $2
- 单个合作 KOL 获取成本 < $60（含采集+谈判）
- 带来的首次分析用户成本 < $20/人（来自增长方案）

## 八、风险与应对

### 风险 1：关键词扩展导致噪音增加
**应对：**
- 先小批量测试（每次 2-3 组新关键词）
- 监控 `category='noise'` 占比，超过 60% 则优化关键词
- 增加人工二次筛选步骤

### 风险 2：预算增加但转化率不提升
**应对：**
- 设置每周预算上限和暂停阈值
- 7 天未新增合格候选则回调预算
- 优先优化现有候选的合作转化，而非盲目扩大池子

### 风险 3：KOL 内容与产品适配度低
**应对：**
- 在画像审阅中增加"产品适配度"维度
- 优先筛选"实际使用分析工具"的 KOL
- 提供试用账号，验证其真实使用场景
