# KOL合作批次与成本账本

入口：运营工作台 → KOL CRM → KOL详情 → 合作批次与投入。KOL长期档案与每次合作分开维护，修改KOL阶段不覆盖历史合作。

## 日常操作

1. 新建合作批次，填写名称、起止时间、目标、约定交付和负责人。时间按UTC+7显示，截止时刻不含在窗口内，单次合作最长366天。
2. 登记计划或已发生成本，关联当前账号的活动初始批次或追加批次。
3. 查看固定活动参与者在活动窗口与合作周期交集内的分析、交易表现。跨活动重新去重，窗口间的空档不计入。
4. 填写复盘结果，将状态改为已完成。系统保存当时的配置、活动、账本和表现作为独立版本。
5. 如需修订，先重新打开合作；再次完成生成新版本。展开历史版本可读取原成本与结果，后到数据不修改旧版。

状态为计划中、进行中、已完成、已取消。已完成/取消的合作须重新打开后才能编辑成本或活动。完成时复盘必填，所需数据源失败或数据尚未进入合作周期时不能冻结。未关联活动或活动窗口无交集时，可保存人工复盘，但使用/交易结果明确显示未提供。

## 成本与效果口径

- 成本类别：内容制作、合作服务费、用户奖励、其他。状态：计划投入、已发生（人工登记）、已作废。修订、作废保留修改记录，不删除原始记录。
- 金额以非负十进制字符串提交，使用最小精度整数存储和整数求和。USD/CNY/THB/EUR账本精度2位，USDT账本精度6位；不接受指数或超出精度的金额。单笔最多10亿货币单位，每批最多500条成本。
- 按币种分别合计计划、已发生；作废不计合计。不换汇，不把成交额视作收入或ROI。
- 活动使用独立固定名单，不因合作标签或当前KOL成员变化而改动。每批最多关联50个活动；沿用共享5000账号、每来源15万条事实等查询预算，超限报错。
- 关联活动同时加入KOL长期活动列表，并即时刷新档案显示；移除本次合作关联仍保留长期关联。仍被任何合作引用的活动不能直接从长期列表解绑。
- 分析次数仍是去重后的观测事件次数，尚非稳定业务操作ID口径。交易沿用已验证身份、链和哈希去重的已知USD金额；没有因果增量推断。
- 负责人为文本备注，当前仍按登录管理账号隔离，没有团队指派权限。

## API

以下路径前缀为 `/api/crm/kols/:id/collaborations`，均校验KOL、合作和活动归属。

| 方法 / 路径 | 用途 |
| --- | --- |
| GET / | 合作列表与分币种成本摘要 |
| POST / | 创建合作批次 |
| GET /:collabId | 当前配置、活动、账本、版本目录和最近200条修改记录 |
| PATCH /:collabId | 编辑配置、完成冻结或重新打开 |
| POST /:collabId/activities | 关联活动 |
| DELETE /:collabId/activities/:activityId | 移除本批次活动关联 |
| POST /:collabId/costs | 登记成本 |
| PATCH /:collabId/costs/:costId | 修订或作废成本 |
| GET /:collabId/review | 未完成时实时表现；已完成时最新冻结结果 |
| GET /:collabId/reports/:version | 单独读取某个历史冻结版本 |

所有现有合作写入携带整数 `expected_revision`，版本冲突返回409；冻结的异步计算结束后再次检查版本。版本目录按需读取报告内容，避免每次打开详情加载全部历史结果。

## 验证

自动化覆盖owner隔离、并发版本、精确金额、币种分开合计、作废、关联约束、重叠名单与交易去重、来源失败禁止冻结、冻结结果不再查询远程源、重开后旧报告不变。真实浏览器验证新建合作、登记两币种成本、关联同步、完成、重开修订及第二版复盘；临时验收记录随后清理。

## 实收、退款与账本ROI（2026-10-15）

合作详情新增独立收益账本：实收/退款、币种、精确金额、凭证编号、发生时间、说明；支持修订与作废、乐观版本校验和历史记录。凭证编号在同一合作内唯一，退款使用正数金额与独立类型，不覆盖原实收。完成合作时，收益流水和按币种计算的结果一起写入不可变复盘版本，旧版未记录的收益口径保持未提供。

净实收=实收−退款；净收益=净实收−已发生成本；账本ROI=净收益÷已发生成本。计划费用与作废流水不计入，不混加币种、不自动换汇。没有收益流水时收益/ROI未知，没有已发生成本记录时成本/净收益未知，明确零投入时ROI不计算。金额用整数最小货币单位与BigInt求和，负净收益正确显示。

当前是人工登记的已发生流水，凭证需自行核验；尚无已确认的自动收入/佣金/财务接口，不从成交额估算收益，也不将账本ROI解释为因果增量。
