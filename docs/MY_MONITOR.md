# 我的监控

新增导航“我的监控”，接口 GET /api/metrics/my-monitor?start=<ms>&end=<ms>&snapshot_id=<id>，支持 Hologres 与 SQLite。查询遵循认证、远程优先及快照缓存；无需读取产品用户明细到浏览器。

页面支持最近1/7/14/30天（含今日），核心指标、六项辅助指标、每日趋势与每日明细。每项显示分子/分母、未成熟人数和采集状态。平台整体统计，不继承其他模块圈选名单。

## 口径

- UTC+7，[start,end) 入组；统一身份去重，排除 acc_。可靠单账号匿名关联后合并；匿名关联不能把匿名行为变成主动登录事实。
- 新访客：本期首次观测 page_viewed，且没有更早业务日的已观测活动。历史不完整时显示首次观测口径，不能宣称真实新增获客。
- 首次筹码分析：全已观测历史最早 chip_analysis_viewed 或 chip_analysis_drilldown。沿用当前事件并集，产品端仍须核实“完成”与“曝光”的业务语义。
- 核心指标：首次访问后24h内首次筹码分析人数 / 本期新访客人数。
- 访问→登录：本期有页面访问的用户中，任一次访问后24h内有主动登录成功者 / 本期页面访问用户。
- 登录→首次分析：本期主动登录时尚未观测分析的用户中，任一次符合条件的登录后24h内完成首次分析者 / 本期符合条件的主动登录用户。
- 登录发起→成功：点击登录按钮后24h内成功登录用户 / 本期点击登录按钮用户。单位是用户，不是尝试次数。
- 免费试用开启：首次主动登录后24h内成功开启免费试用人数 / 本期首次主动登录人数。未接权益资格数据，首次主动登录作为当前分母定义。
- D1/D7：本期首次分析批次，在次日/第7个自然日有页面或筹码分析的人数 / 对应自然日已经结束的首次分析用户。不是7天累计回访；页面事件缺失时为已观测分析回访。
- 转化在入组期后继续观察24h，截至快照；未结束的转化数据为进行中。D1/D7未成熟者排除分母；分母为0显示 —。
- 每日独立去重，周期独立去重；不能将每日人数相加作为周期人数，也不能直接将不同入组分母的率相乘。

## 采集依赖

| 事件 | 要求 |
| --- | --- |
| page_viewed | 页面进入/路由切换成功后上报，包含匿名身份、会话、页面路径、事件ID与客户端时间 |
| login_button_clicked | 用户点击登录入口；保留匿名身份以关联后续账号 |
| login_succeeded | 登录确实成功后上报，必须带实际 user_id |
| chip_analysis_viewed / chip_analysis_drilldown | 按当前后台分析事件并集；必须核实成功完成与曝光区别 |
| free_trial_started | **新增约定**：试用权益成功开启后上报（不是按钮点击），带user_id；建议包含trial_id、started_at、expires_at，并按trial_id防重复 |

本次仅实现增长后台监控与消费契约，未修改相邻产品源码，未发布产品采集事件或部署线上。当前没有事件样本的必要采集项显示“待接入”，有样本不代表覆盖完整。页面访问与试用缺失时不使用业务事件页面上下文或试用点击推算。

## 验证

后端金样覆盖顺序、24h边界、跨日成熟、去重、身份合并、匿名登录排除、缺事件、重复访问；前端覆盖快照锁定、切页晚响应、加载失败。另用真实Hologres只读查询验证查询兼容性，并检查桌面和平板渲染。
