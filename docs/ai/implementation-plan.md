
## 三、待实现功能

### Phase 1: L1 数据解读 (1-2 天)

**目标：** 每日自动生成简报

**任务：**
1. 实现数据获取工具
   - `tools/dataAccess.js` - 调用现有 growth API
   - 复用 `/api/growth/north-star`, `/api/growth/funnel` 等

2. 实现异常检测器
   - `tools/anomalyDetector.js` - 纯统计规则，不用 LLM
   - 环比检测 (±15% 阈值)
   - Z-score 检测
   - 周同比 (避免周末效应)

3. 实现 L1 Agent
   - `agent/dailyAgent.js` - 每日运行
   - 生成简单文字总结
   - 存储到 `ai_findings`

4. 定时任务
   - `scheduler/dailyJob.js` - 使用 node-cron
   - 每天早上 9 点自动运行

**输出示例：**
```
📊 LogEarn 每日增长简报 - 2026-10-26

⚠️ 异常检测：
• 活跃用户：2,345 → 1,993 (↓15%)
• 新注册用户：正常范围

💡 初步观察：
活跃用户下降主要发生在过去 24 小时，建议进一步拆解渠道和用户群。
```

### Phase 2: L2 主动诊断 (2-3 天)

**目标：** 自动多维度拆解异常

**任务：**
1. 实现维度分析工具
   - `tools/dimensionAnalyzer.js` - 按渠道、用户类型、设备等拆解
   - 工具链：queryByChannel, queryByUserType, queryFunnel 等

2. 实现 L2 Agent
   - `agent/investigationAgent.js` - 主动调查
   - LLM 决定调查顺序和深度
   - 存储到 `ai_investigations`

3. 证据链追踪
   - 记录每次查询和发现
   - 生成假设列表

**输出示例：**
```
🔍 深度诊断：活跃用户下降 15%

📊 维度拆解：
• 按渠道：Twitter -30%, Organic +5%, Direct -10%
• 按用户类型：新用户 -25%, 老用户 -8%
• 按设备：移动端 -20%, 桌面端 -5%

💡 假设 (按可能性排序)：
1. Twitter 流量质量下降 (high)
2. 移动端落地页转化率降低 (medium)
3. 产品功能变更影响新用户体验 (low)

📌 需要验证：
• 检查 Twitter 广告投放变化
• 对比移动端和桌面端转化漏斗
• 查看昨日是否有功能发布
```

### Phase 3: L3 增长决策 (2-3 天)

**目标：** 生成可执行的增长建议

**任务：**
1. 实现建议生成
   - `agent/suggestionAgent.js` - 生成建议
   - 优先级评估
   - 预期影响估算
   - 存储到 `ai_suggestions`

2. 实现效果追踪
   - `memory/tracking.js` - 自动复查
   - 3 天后检查指标
   - 更新建议有效性评分

3. 持续学习
   - 记录哪些建议有效
   - 优化假设生成

**输出示例：**
```
💡 增长建议 - 2026-10-26

基于诊断：Twitter 渠道活跃用户下降 30%

📋 建议行动 (优先级：高)：
1. 优化 Twitter 落地页
   • 当前转化率：3.2%
   • 目标转化率：4.5%
   • 预期影响：+10% Twitter 活跃用户
   • 执行时间：2-3 天

2. A/B 测试移动端首页布局
   • 假设：当前布局对新用户不友好
   • 预期影响：+5% 新用户激活率
   • 执行时间：5-7 天

📅 追踪计划：
• 3 天后复查 Twitter 渠道指标
• 如果执行了建议 1，对比前后数据
```

## 四、技术选型和成本估算

### 推荐模型分配

| 任务 | 推荐模型 | 原因 | 成本 |
|------|----------|------|------|
| L1 数据解读 | gpt-4o-mini | 简单文字总结，便宜 | ~$0.01/天 |
| L2 主动诊断 | claude-sonnet-4 | 推理能力强，适合多步调查 | ~$0.05/天 |
| L3 增长决策 | claude-opus-4 | 最强推理，生成高质量建议 | ~$0.10/次 |

**预估每日成本：** $0.10 - $0.50 (取决于异常数量)

### 成本优化策略

1. **统计规则优先：** 异常检测不用 LLM，只用统计规则
2. **缓存结果：** 相同问题 24 小时内不重复调查
3. **按需触发：** L3 只在需要人工决策时运行
4. **模型降级：** 简单任务用小模型，复杂任务用大模型
