# 行为路径派生数据层与会话索引 · 2026-10-25

## 已实施范围

行为路径首图及其按需完整诊断，接入独立 SQLite 派生库：标准化的必要事件字段、用户首次来源及路径首次观测事实、显式会话时间索引。所有业务专题仍共享原来的远程身份和去重规则；本轮未迁移其他专题的 SQL，也未增加分布式任务服务。

远程账号实际没有 CREATE 权限，因此没有在源库创建表或物化视图。源库始终只读。派生库默认位于 backend/data/path-index.db，与运营记录、账号及任务数据库分离；只保存路径/诊断字段白名单，不复制完整信号 payload，页面地址去掉查询串和片段，数据库文件权限为 0600。

## 数据流与一致性

1. 后台独立 worker 每60秒取得真实远程快照，沿用 eventsCte 的时钟过滤、event_id 去重、匿名身份归并、测试账号排除及首次来源口径。
2. 对路径相关标准投影按用户生成内容指纹。仅拉取发生变化用户的事实，按20000行分页；与清单指纹和条数核对后，逐事件比较，只为新增、修改或删除事件写新版本。会话时间索引也只更新变化条目。
3. 一次事务发布 generation。构建或更新失败则回滚；已有读者仍读取旧的完整版本。身份归并变化、迟到事件、源事件修订/删除及新近变得有效的客户端时间会在下次清单中识别。
4. 对外快照绑定精确 generation、snapshot_id 和 cutoff，保留原有15分钟快照寿命；历史行和 generation 至少保留30分钟，随后回收可复用空间。更新后的源数据不会覆盖旧路径快照。
5. 普通 metadata 请求优先返回90秒以内的已发布版本，路径分析直接读取本地索引。首次构建、数据源/格式不兼容、版本缺失、读库异常或索引过期时，使用原快照的远程查询，不切到更新快照。原取数预算超限仍明确报错。
6. 用户主动“刷新数据”仍走真实远程快照，保证强制刷新的语义；这个新快照的首次分析可能走远程，后台下个版本就绪后普通 metadata 请求重新获得索引版本。

指纹清单目前仍会在后台按固定 cutoff 扫描源事件；这是定时摊销并增量传输/存储的方案，不宣称已经接入 CDC 或让源库完全停止扫描。它可以识别修订和删除，无需假设源表只追加。跨分析条件复用的是持久化派生事实，不是跨任务长期保存展开后的用户对象。

## 预算与运行

- 原分析预算不变：150000事件、48MiB紧凑传输等价预算、256MB分析 worker、30秒分析任务、4MiB任务结果。
- 派生库额外保护：最多50000用户、200万相关事件、1GiB数据库页空间；单用户最多150000行/64MiB投影，单页传输48MiB；刷新 worker 512MB、120秒超时。WAL/SHM需要额外工作空间。触及派生预算时不发布新版本，过期后回退远程查询。
- 开关：ENABLE_PATH_INDEX=true。PATH_INDEX_DB 可指定独立文件，相对路径从 backend/ 解析；换源/账号须使用兼容的新派生库。关闭开关并正常重启即可回到原查询；已有带 generation 的有效快照仍可完成原分析。
- backend/.env 已启用本地配置；正常后台启动会预热并自动刷新。不要求修改源库、安装 Redis 或启动另一个运维数据库。
- 一次刷新：npm run path-index:refresh --prefix backend。运行情况位于受认证保护的 GET /api/system/metrics 的 path_index 字段，包括版本、年龄、行数、刷新结果及最后错误。
- 服务不在运行时，派生库不会自行刷新；正常启动会自动恢复，预热期间走远程。

## 验证与实测

真实固定快照，完整比较 payload、全部名单和成员资料，默认/指定起点/向前看/中止动作/7步五种配置，首图及完整诊断均通过：

| 模式 | 相关事件 | 原远程取数 | 索引取数 |
| --- | ---: | ---: | ---: |
| 首图 | 63850 | 3670ms | 1039ms |
| 完整诊断 | 128459 | 5141ms | 1917ms |

两者均1488会话、296用户。以上是同一快照的一次样本，包含解码，不是P95或冷启动承诺。第一次构建183698条事实约28秒；后续一次刷新只涉及6名变化用户，拉取其37521条上下文，而非重新传输全部历史。后续逐事件版本存储回归证明单条追加只新增一行，未变化事件不复制。

真实路由 + 实际256MB分析 worker + 前端相同750ms轮询间隔，隔离的验证用户和内存运营库：metadata约30ms、首图接口约1.53秒、展开完整诊断约3.79秒、重复相同请求命中约7ms。首图和完整诊断使用同一快照；这些数字不含登录、浏览器渲染或首次建库。

增长样本：独立临时索引存入50万条历史事件，按7天读取1000用户/4000会话，实际256MB worker约2.16秒完成，结果约314KB。它验证历史增长后的索引读取与计算；不包含远程清单刷新。
