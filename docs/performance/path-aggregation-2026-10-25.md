# 行为路径聚合性能优化 · 2026-10-25

## 改动

- 路径、节点与连线在遍历会话时累计人数及流量，去除逐节点全量扫描，以及仅用于计数的重复用户和会话 key 数组。
- 图表诊断按节点、连线及结束状态一次建立会话索引，替代为每个诊断重新筛选全部会话。
- 同一分析任务通过 WeakMap 复用事件的页面与设备解析；缓存不跨任务，不长期保留用户事件。
- 原有统计窗口、事件预算、路径显示规则、完整中止路径及下钻名单保持不变。

## 验证

每组前后各4次、交替顺序执行，结果完整 deepEqual（包含名单和诊断）。额外对默认、指定起点、向前看、中止动作、7步、来源、部分窗口及完整诊断8组条件逐项对账。比较基线是本轮修改前的工作区，保留之前未提交的功能。

后端全量342项测试通过，新增重复会话名单、超过展示深度的完整中止路径、推断会话边界及任务内解析缓存回归；git diff --check通过。本轮只修改后端，无前端构建变化。

以上为进程内计算耗时，不能视为页面端到端收益。真实样本数据库取数仍耗时约4.25秒，是当前主要等待；本轮没有修改数据库查询或放宽取数预算。未执行外部部署。
