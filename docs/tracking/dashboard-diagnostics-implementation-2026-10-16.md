# Dashboard 诊断指标实施

日期：2026-10-16。写入范围仅 Logearn-growth；相邻 logearn-web 仅只读核对其 DIAGNOSTICS_HANDOFF.md，不修改产品前端、采集服务或生产数据库。功能位于 Hologres 模式「数据分析 → 行为 → 行为路径」，沿用既有认证、作业、快照、名单与时间线。

## 已实现

- 页面有效停留：读取page_engaged和page_visit_ended，按同身份/访问ID取最大累计可见值；首屏面板、入口页表、访问明细均复用该值。实际0与未知分开。
- 页面诊断会话：同标签页30分钟无采集活动分段，入口/首屏/首页跳出共用分段。停留检查点跟随所属访问，不单独生成新入口。上方历史行为路径继续尊重显式session_id，页面已说明两者不能直接比较会话总数。
- 首页跳出：仅主页面 /、/cn、/en；区分有效互动、明确短停留跳出、观察中、未知。短停留只接受route_leave/unmount的有效结束证据，单纯hidden/pagehide或缺ID不足以判跳出。可判定分母不代表全体访客；长停留更易确认，样本有选择偏差。可按来源、设备、视口、应用与诊断采集版本下钻去重用户名单。
- 分析请求：analysis_request_id关联开始/结果，成功、空结果、失败、明确取消、待观察、未知、冲突分别统计；终态按发起批次，支持跨期完成。明确终态成功率、已观测完成占比、终态/页面/Token关联覆盖、结果分组耗时P50/P90、等待中明确取消、离开发起视图后完成、可验证重试关联及失败原因。
- 登录尝试：login_attempt_id关联，主动取消与失败分开，按方式/入口/设备/版本等比较；不修改现有manual/auto_restore/未知登录口径。
- 页面核心加载：page_load_id关联started/finished，ready/failed/cancelled分别计算；document/spa/float与content_type分开，不拿page_viewed当作核心数据就绪证明。呈现后补的page_visit_id可用于覆盖统计。
- 卡片曝光：按同身份、page_visit_id、item_exposure_id去重曝光及关联点击；重复点击仅计一个曝光对象已点击。点击可跨统计期但限曝光后24小时，未关联点击单列，不反向造曝光。entry_module和list_type分别展示。
- 同次Token访问：点击→详情→分析请求成功按Token/链/token_visit_id及严格时间顺序关联；缺访问ID单列，观察窗口24小时；完成比例标为含未成熟样本的已观测值。原始曝光/下钻北极星不变。
- 首次价值：基于完整已加载的观测历史，首次页面后24小时用户主动分析请求成功；仅成熟批次进入转化分母，未成熟单列。首次成功分析D1/D7按UTC+7完整自然日成熟，保留采集覆盖不足声明；不替换既有北极星留存。

## 数据与限制

behaviorPaths查询使用固定字段白名单投影，不拷贝完整原始signal载荷、登录凭证或钱包签名。为避免跨会话重试、首次价值和回访被截断，加载所选期候选用户的全部已观测相关历史；保留150000事件/48MB查询预算和结果截断提示。页面明细最多1000条、新请求明细各100条，统计与名单在截断前计算；请求明细展示上限不等于完整事件数。

新事件仍不进入旧行为路径的业务节点字典，避免把计时/诊断事件冒充操作；但可在用户时间线看到中文诊断事件名。新页面证据与核心请求的关联字段缺失时保持未知，缺终态超30分钟只标结果未知，不直接判失败或离开。

目前新事件的生产部署与逐event_id联调仍待完成。未观测对应事件时整个面板显示待接入，不展示虚构零成功率或零点击率。诊断版本来自properties.diagnostics_version；首次观测不是部署时间，尚不能证明连续完整采集。
