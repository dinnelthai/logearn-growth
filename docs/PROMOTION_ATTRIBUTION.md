# 推广链接与 UTM 归因

KOL详情、活动详情共用推广链接面板。生成时关联当前对象，填写落地页、名称、utm_source、utm_medium、utm_campaign，可选utm_content；保留原有查询参数，追加唯一le_link。链接支持搜索、分页、复制。

目标站需要将完整落地地址记录在现有事件的properties.page_url（或完整page）中，并保留le_link。应用不修改远程埋点，不向目标站发布脚本，也不以服务端重定向次数冒充用户。旧事件没有标识时无法追溯确认。

当前模型：所选统计期内，按当前owner保存的推广链接中每个已观测身份的首次触点归组；并列按事件ID稳定选择。要求完整地址的origin/path与保存目标匹配，触点不能早于链接创建。跨链接归组去重，重复访问不重复计人。匿名身份单列；事件源唯一关联到注册账号后可以合并。使用和交易仅统计已匹配注册用户，且发生在其触点之后、所选期内；交易仍按现有身份校验、链+哈希去重和已知USD金额口径。

这是期间首次已观测触点，不是用户终身首触、不证明新增获客、因果贡献或新增收入。分析、交易、账号查询失败保持未知或报错；没有历史标识的访问不分配给手工标签。报告最多5000个注册账号、150000条触点及32MB查询预算，超出时要求缩小周期。

接口均需登录且隔离owner：GET/POST /api/promotions；POST /api/promotions/:id/report（start/end）。生成链接不访问外部目标站；报告只读远程事件和业务事实。
