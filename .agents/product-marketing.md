# LogEarn 产品与增长背景

**Document version:** v3
**Last updated:** 2026-10-24
**状态：** 基于当前仓库的初稿；产品定位、商业模式和用户动机尚待业务方确认。

## Product Overview
一句话：LogEarn 是围绕链上 Token 发现、筹码与持有者分析、策略信号及交易的产品；本仓库是其增长分析与运营后台。

产品功能包括喊单、信号榜单、热门/FOMO、Token 详情、筹码分析、关联钱包、AI 策略、交易与推荐奖励。后台提供北极星、渠道、漏斗、留存、路径、交易质量、推荐、人群、积分签到、活动监控及跨模块分析任务。

类别暂定为链上分析与交易工具。交易手续费/推荐佣金、API 充值额度、NFT 购买存在业务数据线索，但正式定价、权益、收入结构与净收入未确认。

## Target Audience
假设核心用户是需要发现 Token、分析筹码或跟踪信号的链上交易用户；另有策略使用者、推荐贡献者与 API 用户。地区、语言、经验程度及付费意愿尚无可靠用户研究。
待验证的任务：筛选值得进一步研究的 Token；理解筹码与持有者结构；持续跟踪策略与钱包；执行交易。
后台使用者是增长、产品及运营人员。

## Personas
消费端以行为分群代替未经验证的人设：首次分析、重复分析、策略使用、交易、有价值线索未观测使用、推荐贡献、积分签到。API 是否为独立 B2B 业务待确认。

## Problems & Pain Points
用户可能面临信息分散、筛选成本高、信号难判断和交易流程摩擦，均属假设。未取得真实访谈，不能宣称已验证痛点或投资表现。
当前增长团队的已确认问题：身份迁移、采集覆盖、会话边界和归因证据不足，容易将无观测误读为无使用。

## Competitive Landscape
尚未开展外部竞品调研，不记录未经验证的竞争优势。替代方式可能包括手工链上查询、社群信号、其他分析工具与交易入口，需用户访谈验证。

## Differentiation
仓库体现的组合能力：发现入口 → Token 分析 → 策略/信号 → 交易 → 推荐；产品实际体验及相对优势待验证。
分析后台的明确能力是按同一人群、日期和快照跨模块分析，并从指标下钻到名单与事件时间线。

## Objections
用户可能关注数据可信度、策略理解成本、钱包连接与费用，尚未验证。不能以“保证收益”等措辞说明价值。
不匹配用户画像未知，暂不排除特定用户群。

## Switching Dynamics
Push/Pull/Habit/Anxiety 均待访谈。可检验假设：更方便的分析与信号拉动使用；既有社群、工具和钱包习惯增加迁移成本。

## Customer Language
无真实客户原话。产品术语包括筹码峰、喊单、信号、AI 策略、邀请码、积分与 API Credits。
积分、API Credits、交易等级、NFT 权益分别处理，不能互相替代。首次观测不等于首次使用；推荐绑定不等于新增获客。

## Brand Voice
暂定：中文、直接、证据优先、具体可执行。品牌官方语气待确认。

## Proof Points
以下来自 2026-10-11 仓库审计与实施记录，非本次实时数据库刷新：
- 注册账号 6,860；双方匹配账号的有效一级被邀请用户 1,953；贡献推荐人 708。
- 严格先后关系下继续推荐用户 164、下一代账号 384；204 位同时间关系顺序未知。累计传播产出约 0.20，不是标准病毒系数。
- 交易表约 17.4 万记录、481 位用户，覆盖远早于近期行为事件；不能直接计算同周期注册到交易转化。
- 积分接入记录：1,134 位注册账号有积分流水；近7天54人获得积分、34人签到、4人连续签到至少3天。不同记录快照不能拼成一个统一实时漏斗。
- 路径审计发现筹码展示、页面浏览与页面停留记录漏报/缺失；当前有效分析采用展示或筹码下钻并集，按用户去重。
无客户证言、正式收益证明或可引用的增长提升结果。

## Goals
已确认阶段目标：截至2026-11-30，最近7天至少4个不同UTC+7自然日完成筹码分析或下钻的去重用户达到200；建议另查连续两周达标，但尚非用户新增硬要求。该四日核心指标与原日北极星分别保留。
2026-10-24只读基线：10/17—10/23四日核心34位，上期38位，持续28、新进入6、跌出10；2—3日用户19位。身份尚未核实排除员工/测试，历史与连续采集仍未知。证据见output/core-users-2026-10-24/baseline.json。
当前后台北极星：有效分析用户数；真实库实现使用 chip_analysis_viewed 或 chip_analysis_drilldown 并集，按 UTC+7 业务日统计。
2026-10-12 用户明确确认业务意图为“成功完成筹码分析或下钻的每日去重用户”；曝光可见性不应成为完成指标的唯一前提。空结果、缓存、后台引擎计算须分别定义，审计见 docs/SITE_METRICS_AUDIT_2026-10-12.md。
增长研究应验证：首次有效分析能否预测重复使用、策略使用与交易贡献。注册、积分及邀请总量是辅助指标。
尚缺：实际执行人手、当前有效预算确认、成熟留存、渠道成本、净收入、奖励成本与可靠首访归因。此前方案记录30天最多1000美元，后续规划须明确适用期间。
当前范围：后台分析与监控；生命周期仅分析，不恢复自动发送。产品埋点发布与端到端验收是外部依赖。
