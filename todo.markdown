- 当前需求以代码、`docs/product/`、`docs/tracking/` 最新实施文档及本轮 update 为准。下方清单是 2026-10-06 起累积的历史任务记录，不能仅凭旧勾选状态认定生产已验收。

- 验证：后端执行 `npm test`；前端执行 `npm test`、`npm run build`；界面修改做浏览器验证；提交前执行 `git diff --check`。
- 数据原则：只从已加载事实计算；缺失不当作 0，不运行生成器补造业务数据，真实源失败不回退示例数据。
